# Invitation de mariage — Iheb & Chanaz

Site responsive en français pour le mariage d'Iheb Gargouri et Chanaz Sanaa.

## Aperçu local
Ouvrez `index.html` dans un navigateur récent. Pour le publier, téléversez tous les fichiers et le dossier `assets` sur votre hébergement web.

## Personnalisation
- `index.html` : textes, date, lieu et photo.
- `styles.css` : style clair, écran de lune, animations et mise en page.
- `script.js` : interaction de la lune et navigation.
- `assets/iheb-chanaz-photo.png` : photo du couple affichée en noir et blanc.
- `assets/moon.svg` : icône de lune gibbeuse croissante.
